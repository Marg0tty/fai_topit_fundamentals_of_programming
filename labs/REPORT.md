# Лабораторная работа № 3
## Алгоритмы, коллекции и функции

### Цель
Научиться строить алгоритмы, использовать коллекции Python, разбивать программу на функции и оценивать сложность.

## Задание 1. Условия и классификация
Функция `classify` проверяет допустимость баллов и пропусков, определяет уровень результата и пояснение к типу работы.

| Баллы | Ожидаемый уровень без снижения |
|---:|---|
| 0 | недостаточный |
| 59 | недостаточный |
| 60 | удовлетворительный |
| 74 | удовлетворительный |
| 75 | хороший |
| 89 | хороший |
| 90 | отличный |
| 100 | отличный |

При числе пропусков больше трёх уровень понижается на одну ступень, но не ниже недостаточного. Сначала проверяется диапазон, поэтому недопустимые данные не классифицируются. Ветка `case _` обрабатывает неизвестный тип работы.


1. Проверить допустимые диапазоны.
2. По баллам определить уровень.
3. При более чем трёх пропусках понизить уровень.
4. По типу работы сформировать пояснение.
5. Вернуть строку результата.

Сложность обработки одной записи: `O(1)` времени и `O(1)` дополнительной памяти. Для `n` записей — `O(n)` времени.

## Задание 2. Циклы и алгоритмы
Сумма, минимум, максимум и количество чётных значений вычисляются одним проходом. Среднее вычисляется после суммы, затем вторым проходом подсчитываются значения выше среднего.

| Алгоритм | Время | Дополнительная память |
|---|---|---|
| Статистика списка | `O(n)` | `O(1)` |
| Линейный поиск | `O(n)` | `O(1)` |
| Проверка простоты | `O(√n)` | `O(1)` |
| Сортировка выбором | `O(n²)` | `O(n)` в данной реализации |
| Бинарный поиск | `O(log n)` | `O(1)` |

Достаточно проверять делители до квадратного корня: если `n = a * b`, то хотя бы один множитель не превосходит `√n`.

Для сравнения поисков линейный поиск в худшем случае выполняет `n` сравнений, бинарный — не более порядка `log₂(n) + 1`.

## Задание 3. Коллекции
Использованы:
- `set` для уникальных студентов и работ;
- `list` для истории попыток;
- `dict` для быстрого доступа по ключу;
- кортеж `(student, laboratory)` в качестве составного ключа.

Множество хранит только уникальные значения. Кортеж неизменяем и хешируем, поэтому подходит для ключа словаря; список изменяем и не хешируется. Словарь удобнее списка, когда нужен частый поиск по составному ключу.

Средняя сложность добавления в множество и словарь — `O(1)`, поиска по ключу словаря — `O(1)`. В худшем случае хеш-таблицы могут работать медленнее. Добавление новой попытки обновляет структуры без их полного построения.

## Задание 4. Функции и LEGB
- `arithmetic_mean` возвращает среднее непустого списка, иначе возбуждает `ValueError`.
- `normalize_name` убирает лишние пробелы и нормализует регистр.
- `build_report` формирует строку отчёта; `precision` и `prefix` — только именованные параметры.
- `collect_tags` удаляет пустые и повторяющиеся теги.

Функции не изменяют входные коллекции. Проверки выполняются через `assert`. Распаковка списка демонстрируется оператором `*`, словаря — оператором `**`.

Схема LEGB:
1. **L (Local)** — локальная область функции.
2. **E (Enclosing)** — область внешней функции.
3. **G (Global)** — глобальная область модуля.
4. **B (Built-in)** — встроенные имена Python.

В `scope_demo` вложенная функция меняет `value` внешней функции с помощью `nonlocal`; глобальная переменная `course` остаётся без изменений.

У функции `add_result(value, results=[])` список по умолчанию создаётся один раз при определении функции и разделяется между вызовами. Исправление — использовать `None` и создавать новый список внутри функции.

Фабрика `make_threshold_checker` возвращает функцию, которая сохраняет свой порог в замыкании. Поэтому проверки с разными порогами независимы.

## Задание 5. Анализатор результатов
Контракты:
- `mean(values)`: среднее непустой последовательности или `None` для пустой.
- `minimum(values)`, `maximum(values)`: крайнее значение или `None` для пустой последовательности.
- `classify(score)`: категория результата, `нет данных` для `None`.
- `student_summary(name, results)`: словарь с именем, средним, минимумом, максимумом и категорией.
- `group_summary(students)`: количество студентов, категории и среднее по всем имеющимся оценкам.
- `find_top_students(students)`: список всех лидеров; пустой список, если нет оценок.
- `format_report(student_data, group_data)`: готовый текст отчёта.

| Сценарий | Ожидаемое поведение |
|---|---|
| Обычная группа | Статистика по каждому студенту |
| Один студент | Один элемент статистики |
| Несколько лидеров | Все студенты с одинаковым максимальным средним |
| Пустая группа | Среднее `None`, категории равны нулю |
| Студент без оценок | `нет данных`, минимум и максимум `None` |
| Границы 60, 75, 90 | Категории меняются на заданных границах |

Построение общей статистики выполняется за `O(N)`, где `N` — общее количество оценок, поскольку каждая оценка обрабатывается ограниченное число раз. Дополнительная память — `O(S + N)` для `S` студентов и сохранённых результатов/сводок.
